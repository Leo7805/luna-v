# LunaV Privacy Policy

Last updated: July 31, 2026

LunaV is a Chrome extension that lets users control native HTML video playback with keyboard shortcuts.

## Data Handling

LunaV does not collect, store, transmit, sell, or share personal information or user data.

To provide video controls, the extension runs locally in the active web page and interacts only with native HTML video elements. It may read the current website hostname and video playback state to select the correct video-control behavior.

## Data LunaV Does Not Collect

LunaV does not collect or transmit:

- Web page content, form input, or keystrokes.
- Browsing history, visited URLs, or search activity.
- Account information, passwords, cookies, or authentication data.
- Video titles, viewing history, playback progress, or analytics data.
- Device identifiers, advertising identifiers, or usage telemetry.

## Local Operation

All LunaV controls run locally in the user's browser. The extension does not operate a server, make network requests, or use third-party analytics or advertising services.

## Changes to This Policy

If LunaV's data practices change, this policy will be updated before the changed behavior is released.

## Contact

For questions about this policy, open an issue in the [LunaV GitHub repository](https://github.com/Leo7805/luna-v).
